# Memoization — бриф на редизайн (для Claude Design)

Рабочий документ: сюда складываем всё, что должно измениться в интерфейсе. Пункты
добавляются по мере обсуждения; раздел без пунктов означает «пока без замечаний».

## О приложении

Android-тренажёр словарного запаса с интервальным повторением. Пользователь собирает
пары слов в стеки и повторяет их по расписанию, которое растягивается по мере того, как
слово вспоминается правильно. Термины — по `CONTEXT.md`:

- **Стек** (stack) — именованный набор пар слов, обычно один язык.
- **Пара слов** (word pair) — что вспоминаем и ответ, плюс состояние расписания.
- **Сторона** (side) — одно направление припоминания пары; несёт своё расписание FSRS.
- **Уровень** (level) — цвет по stability стороны, от Level1 до Learned.
- **К повторению** (due) — сторона, у которой наступил день следующего повторения.
- **Библиотека** (library) — все стеки на устройстве.

Стек: Jetpack Compose, Material 3, одна Activity, Compose Navigation.

## Экраны

### Библиотека (FolderScreen)

Стартовый экран. Список стеков с прогрессом, FAB создания стека, боковое меню
(настройки, уведомления). Свайп по стеку удаляет его.

_Пункты редизайна: пока нет._

### Стек (StackScreen)

Список пар слов стека, новые сверху. Свайп влево открывает кнопку удаления, удаление
можно отменить через snackbar. Кнопки «добавить пару» и «Учить» (последняя — только
если есть пары к повторению). Редактирование названия стека через диалог.

_Пункты редизайна: пока нет._

### Новая / редактирование пары (AddNewPairScreen)

Два поля: слово и объяснение (многострочное), кнопка перевода через Lingvanex,
выбор языков «с / на». Подтверждение — FAB.

_Пункты редизайна: пока нет._

### Экран заучивания (MemorizationScreen)

Показывается одна карточка со стороной к повторению: лицевая сторона — слово, оборот —
объяснение (или наоборот, если в настройках выбрано другое направление). Тап по карточке переворачивает её (анимация поворота вокруг вертикальной
оси). Под карточкой три оценки: Легко / Сложно /
Не помню — они меняют уровень пары и подгружают следующую; «Не помню» возвращает слово в
конец очереди этой же сессии. Когда очередь пуста — диалог «стек пройден».

Пункты редизайна:

- Нужно, чтобы было понятно, что карточку можно перевернуть. Сейчас карточка выглядит
  как статичный лист с текстом, и без подсказки не очевидно, что за ней есть оборот и что
  по ней надо тапнуть.
- Прогресс сессии — визуальный показатель (полоса/шкала: сколько карточек пройдено из
  всех в сессии), а не текст «осталось N». Сейчас временно стоит текстовая подпись над
  карточкой — заменить на визуальный индикатор.

### Настройки и уведомления (MenuDrawer, NotificationSettingsView, LearningSettingsView)

Раздел «Learning»: какие стороны пары учить — слово → объяснение, объяснение → слово или обе
(три радио-кнопки, подпись «A new side starts from scratch»). Ниже — уведомления: дни недели и
число напоминаний в день.

Пункты редизайна:

- Раздел «Learning» сейчас — простой список радио-кнопок в стиле раздела уведомлений; нужен
  вид, объясняющий, что такое «сторона», без чтения документации.

## Общее

Пункты редизайна:

- Продумать цвета для светлой и тёмной темы. Сейчас Compose-тема (`ui/theme/Theme.kt`)
  задаёт только светлую палитру (и для Material 2, и для Material 3), а XML-тема окна в
  `values-night` — системная тёмная. Итог при автоматическом переключении телефона в тёмную
  тему: экраны без явного фона показывают тёмный фон окна, а текст остаётся чёрным из светлой
  палитры — подписи под кнопками на экране заучивания почти не видны. Нужны две согласованные
  палитры (фон, поверхность, текст, акценты, цвета уровней и кнопок оценок) и правило: приложение
  следует системной теме.
